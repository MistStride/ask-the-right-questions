# 关卡内容质量标准：从“找明显错误”到灰度判断

这份标准用于新关卡评审和现有关卡精修。目标不是把题目写得更绕，而是让玩家练习现实中真正困难的判断：**多个选项都有一点道理，但能排除的解释、支持的结论强度不同。**

## 一、核心原则

### 1. 最强错误项必须“部分正确”

每个 D2/D3 关卡至少有一个近失误。评审者必须能同时写出：

- 它为什么诱人：包含哪条真实信息、合理顾虑或正确方向；
- 它为什么不足：没有检验哪个核心断言，或仍排除不了什么替代解释。

如果只能解释“它显然无关”或“书里不是这么说”，它不是合格的近失误。

### 2. 证据强度要匹配结论强度

题目不只问“证据是真是假”，还要问它最多能支持多强的结论。优先使用以下结构：

- 真实数据 + 过度外推；
- 相关信息 + 因果结论；
- 样本内部改善 + 总体代表性仍不足；
- 更精确的个案 + 仍然只是个案；
- 信源线索 + 尚未检验论证内容。

### 3. 信息缺失必须能改变判断

缺失信息不能只是“知道了更完整”。它应至少改变以下一项：结论方向、可信度、适用范围或行动紧迫性。

### 4. 反馈解释判断过程，不只公布答案

即时反馈采用三级语义：

| 结果 | 含义 | 反馈要回答 |
|---|---|---|
| 命中 | 直接检验核心断言 | 它排除了哪个关键解释？ |
| 近失误 | 方向相关但证据力不足 | 为什么诱人？还缺哪一步？ |
| 偏题 | 没有改变当前判断 | 它与当前结论为什么无关？ |

避免只写“回答错误”“再想想”“这不是关键”。

## 二、难度标准

### D1：建立动作

- 一个主要推理缺口；
- 允许一个明显错误项，但必须有一个合理近失误；
- 反馈明确指出“证据—结论”之间的断点。

### D2：比较证据力

- 至少两个看似合理的替代选项；
- 玩家需要区分“改善研究”和“足以支持结论”；
- 场景至少包含一个可能的混杂因素、范围外推或指标偷换。

### D3：管理不确定性

- 不把正确项固定写成最长、最学术或唯一问句；
- 同时存在两种以上合理解释；
- 近失误能够改善判断，但不能单独解决核心问题；
- 结算解释剩余不确定性，不把专家答案包装成绝对真理。

## 三、五引擎的最低门槛

- **X-Ray**：D2/D3 至少两个干扰节点；干扰项应像结论、理由或假设，而不是纯背景废话。
- **Courtroom**：D2/D3 至少两个近失误问题；每个近失误都必须有中英双语专属解析。
- **Calibration**：答案必须是合理区间而非单一魔法数字；高难区间更窄，但仍容纳可辩护差异。
- **Defusal**：D2/D3 至少两个可疑但无须拆除的点，避免玩家只凭唯一高亮猜答案。
- **Tamer**：每个冲动都必须包含一个近失误；即时解释它为什么相关但没有检验核心断言。

这些最低门槛由 `tests/unit/content.quality.test.ts` 自动检查，`npm run audit:content` 可单独执行。

## 四、人工审题清单

提交关卡前，由非作者试玩一次并回答：

1. 不看解析时，能否在两个选项之间认真犹豫？
2. 最强错误项是否包含真实且相关的信息？
3. 正确项是否因为“最长、术语最多、语气最谨慎”而暴露？
4. 更换人物立场后，判定标准是否仍然成立？
5. 解析是否明确说明证据最多能支持到哪里？
6. 中英文是否保留同样的灰度，而不是一边更明显？

任一 D2/D3 关卡在第 1、2、5 项答“否”，不应合入。

## 五、一个合格近失误示例

结论：“自愿参加四天工作制试验的团队，季度产出提高 18%，因此该制度能提高所有团队效率。”

- **命中**：询问参与团队原本是否更强，并比较同期未参与的相似团队；它直接处理自选偏差和共同时间因素。
- **近失误**：询问员工是否更满意；满意度重要且相关，但它不是效率指标。
- **偏题**：询问还有多少知名公司采用；流行度不能修复当前研究的因果缺口。

关键不在于把近失误写得“像正确答案”，而在于它确实有价值，只是价值不足以承担当前结论。
